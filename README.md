# ConnectorMixinPatches
A mod that patches mixins of Fabric mods with MixinSquared to work with Connector on newer versions of Forge.  
This is a personal experimental project, and can only be tested in an actual Minecraft instance.  

Since MixinSquared applies patches after Connector, the fix method used by this mod can only fix mixin transformer errors and not jar transformer errors.  

Current mods:  
- Bewitchment (with Forge 47.1.7+)  
- Spectrum (with Forge 47.4.2+)
